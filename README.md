# まなびのクラフト冒険

小学1年生の算数で木材を集め、橋をつくって宝箱へ進む、小さな3Dブラウザゲームです。

**あそぶ:** https://metaborin.github.io/manabi-bridge-adventure/

## 操作

- 矢印キー / WASD：移動
- E / Space：近くのものを調べる
- Tab / Enter：画面のボタンを選ぶ・決定
- Esc：きゅうけい
- 画面の方向ボタンでも移動できます。

「はじめから」で出発し、木材を3か所で集め、橋を3回つくって宝箱へ進みます。まちがえても木材は減りません。進み具合は同じブラウザに自動保存され、「つづきから」で再開できます。保存が許可されていない環境では画面に案内します。

現在は1人用・1ステージの試作です。学年2〜6と次の冒険は準備中です。スマートフォンやChromebook実機、子どもによる遊び心地の評価は未実施です。

このリポジトリはブラウザで配信するビルドを格納しています。3D描画に使用するthree.jsのライセンスは THIRD-PARTY-NOTICES.txt を参照してください。

## アプリ追加とオフライン保存（PWA）

- HTTPSの公開URLを対応ブラウザで開き、「アプリ・オフライン」→「オフライン用に保存」で全ファイルの確認が終わるまで待ってください。初回の準備には通信が必要です。
- 準備完了後は、同じ端末・ブラウザから通信なしでゲームを開けます。「アプリを追加」またはブラウザのインストールメニューで独立したウィンドウに追加できます。追加とオフライン保存は別の操作です。
- 保存中は進捗を表示し、中断できます。通信失敗・容量不足・不完全な更新では、新しい一式を使わず、保存済みの版とセーブを残します。
- 更新を準備しても、ゲーム中に再読み込みしません。ゲームを終え、このアプリのタブ・ウィンドウをすべて閉じてから開き直してください。
- キャッシュはこのアプリのURL範囲と名前で分離しています。他のアプリのキャッシュ、localStorage、IndexedDBを削除しません。
- ブラウザが保存を削除した場合は、通信できる場所で再び準備してください。サイトデータの手動削除はゲームの記録も消します。OSへの実際のインストール、Chromebook・スマートフォン実機は別途確認が必要です。

保存対象はゲーム本体を含む約0.6 MBです。既存のブラウザ内セーブをそのまま使います。このリポジトリは引き続き配信物専用です。
